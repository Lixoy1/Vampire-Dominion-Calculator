# Исследование входа и синхронизации Game of Vampires

## Проверка приложенного эталонного архива

Проверены `scripts/app.js`, `scripts/engine.js`, `scripts/data.js`, HTML, package manifest и зависимости. В архиве:

- нет формы входа в игровой аккаунт;
- нет полей логина/пароля и реализации токенов/сессий;
- нет запросов `fetch`, `XMLHttpRequest`, WebSocket или клиента API игры;
- нет серверной функции получения ресурсов, героев, инвентаря или прогресса аккаунта;
- профиль сохраняется в `localStorage`, переносится через JSON-импорт/экспорт.

Следовательно, авторизация и автосинхронизация не реализованы в предоставленном приложении.

## Что известно из официальных публичных поверхностей

- Страница приложения Game of Vampires: Twilight Sun указывает разработчика Dream Plus. В опубликованной истории версий описаны переключение серверов на экране входа и привязка аккаунта по электронной почте.
- Официальный платёжный портал позволяет выбрать сервер, ввести Character ID и имя персонажа для проверки/оформления покупки. Это не публичная выгрузка инвентаря или характеристик.
- В найденных публичных материалах не обнаружена документация API/SDK для стороннего чтения игровых профилей.

## Безопасный путь интеграции

1. Запросить у Dream Plus подтверждение наличия официального read-only API/SDK или формата экспорта профиля.
2. Если разработчик предоставляет API, реализовать серверный коннектор с OAuth/официальным токеном, минимальными правами и безопасным хранением refresh token. Не хранить пароль от игры в браузерном `localStorage`.
3. Если API нет, поддержать импорт файла/структурированной выгрузки, предоставленной официальным клиентом или поддержкой.
4. До появления официального интерфейса оставлять ручное редактирование и JSON backup; не делать вид, что обычная проверка Character ID синхронизирует аккаунт.

## Что не реализовано

Прямой вход, получение токена, чтение ресурсов с игрового сервера и фоновая синхронизация не реализованы и не заявляются как доступные.

## Дополнительная проверка способов входа (10 ноября 2026)

В открытой инструкции стороннего сервиса Game of Vampires Bot описан отдельный процесс привязки персонажа: выбор региона и номера сервера, затем выбор провайдера, к которому привязан игровой персонаж (Google, VK или Facebook). Это вход в сторонний Assistant, а не опубликованный API/SDK Dream Plus для чтения данных персонажа. Инструкция: https://gameofvampires.com/en/game-assistant-add-character/ и https://gameofvampires.com/en/game-assistant-guide/.

В истории версий официального приложения Game of Vampires: Twilight Sun зафиксированы переключение сервера на экране входа и привязка аккаунта по email. В этой записи не описан API или экспорт данных для сторонних калькуляторов: https://apps.apple.com/us/app/game-of-vampires-twilight-sun/id6469515429.

В пользовательском соглашении Dream Plus есть запрет на неразрешённые сторонние боты и автоматизирующее ПО, предназначенное для изменения игрового процесса: https://www.dreamplusgames.com/en/service/. Поэтому не копируем в наш калькулятор OAuth-поток стороннего Assistant, не запрашиваем пароль/куки Google, VK или игрового аккаунта и не пытаемся обходить клиент игры. Такой способ также не даёт нам легального/поддерживаемого контракта для надёжного чтения инвентаря.

**Решение для проекта:** оставить безопасный локальный профиль, импорт/экспорт JSON и ручное редактирование; реализовывать автоматическое получение данных только после появления письменного разрешения/официального API или формата экспорта от Dream Plus. Telegram initData идентифицирует пользователя Telegram внутри Mini App и не является авторизацией в Game of Vampires.
