# Хроники Наследия — Crimson Obsidian

Полнофункциональный локальный помощник Vampire Dominion без VIP-блокировок. Десять рабочих разделов: Господство; Оракул; Конклав и Сад; Уровни и Кровь; Таланты и Опыт; Вдохновения и Веяния; Кровные узы; Облики; Призыв; Сумка и Очки.

## Что включено

- Каталог из 68 смотрителей, 45 партнёров, 237 предметов и 105 обликов.
- 8 ступеней прорыва, 180 уровней Конклава, 210 уровней Сада и 155 строк кривых Веяний.
- 496 оригинальных локальных WebP-иконок; изображения загружаются из `assets/icons/` без CDN.
- Расчёт Господства, Конклава, Сада, уровней, Кровных уз, сумки и опыта Гильдии.
- Ручная настройка профиля и нескольких аккаунтов, локальное сохранение, импорт/экспорт JSON.
- OPTIMIST ORACLE: импорт серверных JSON-ответов, отображение итоговых атрибутов, исходного best_path и следующих шагов по next_cost / next_gain.
- Снимок API хранится локально в выбранном профиле; личные игровые данные не попадают в репозиторий.
- Автораспределение Конклава, Сада и уровней смотрителей с резервированием предметов прорыва.
- Атомарное применение плана: сначала проверяются ресурсы, затем списываются Кровь, очки Конклава/Сада, материалы прорыва и очки Доверия.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run check
npm test
npm start
```

Также проект можно публиковать как статический сайт: `index.html` — точка входа.

## Игровая синхронизация

Приложенный проект-эталон не содержит входа в Game of Vampires, игровых API-запросов, получения токена или выгрузки аккаунта. Эта версия не запрашивает пароль от игры и не имитирует авторизацию. Сейчас поддерживаются локальные профили и JSON-резервные копии. Для прямой синхронизации необходим официальный API/SDK либо поддерживаемый разработчиком формат экспорта. Подробности и границы реализации — в `docs/GAME_SYNC_RESEARCH.md`.

## Oracle и точность игровых данных

Oracle принимает JSON-ответы, полученные пользователем из режима разработчика/выгрузки «Помощника Дампира». Серверные `best_path`, `next_cost`, `next_gain`, `total` и `attributes` отображаются без подмены приближёнными формулами. Эффективность сравнивается отдельно внутри каждого ресурса: Кровь не сравнивается с тканью, Доверием или очками Конклава. Импортированный снимок хранится локально в выбранном профиле и может быть экспортирован отдельно.

Старый локальный калькулятор остаётся доступен. Его формулы стоимости уровней в Крови и Кровных уз отмечены в исходном движке как приближённые; их нельзя путать с расчётом Oracle по серверному JSON. Прямой вход и фоновая синхронизация с Game of Vampires не реализованы: для этого нужен официальный API/SDK или поддерживаемый разработчиком формат экспорта.
