# Хроники Наследия — Crimson Obsidian

Полнофункциональный локальный помощник Vampire Dominion без VIP-блокировок. Девять рабочих разделов: Господство; Конклав и Сад; Уровни и Кровь; Таланты и Опыт; Вдохновения и Веяния; Кровные узы; Облики; Призыв; Сумка и Очки.

## Что включено

- Каталог из 68 смотрителей, 45 партнёров, 237 предметов и 105 обликов.
- 8 ступеней прорыва, 180 уровней Конклава, 210 уровней Сада и 155 строк кривых Веяний.
- 496 оригинальных локальных WebP-иконок; изображения загружаются из `assets/icons/` без CDN.
- Расчёт Господства, Конклава, Сада, уровней, Кровных уз, сумки и опыта Гильдии.
- Ручная настройка профиля и нескольких аккаунтов, локальное сохранение, импорт/экспорт JSON.
- Автораспределение Конклава, Сада и уровней смотрителей с резервированием предметов прорыва.
- Атомарное применение плана: сначала проверяются ресурсы, затем списываются Кровь, очки Конклава/Сада, материалы прорыва и очки Доверия.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run check
npm test
npm start
```

Также проект можно публиковать как статический сайт: `index.html` — точка входа.

## Игровая синхронизация

Приложенный проект-эталон не содержит входа в Game of Vampires, игровых API-запросов, получения токена или выгрузки аккаунта. Эта версия не запрашивает пароль от игры и не имитирует авторизацию. Сейчас поддерживаются локальные профили и JSON-резервные копии. Для прямой синхронизации необходим официальный API/SDK либо поддерживаемый разработчиком формат экспорта. Подробности и границы реализации — в `docs/GAME_SYNC_RESEARCH.md`.

## Ограничения расчётов

Движок переносит расчёты из эталонного архива. В самом эталоне формулы стоимости уровней в Крови и Кровных уз обозначены как приближённые; без контрольных значений из игрового клиента нельзя заявлять их абсолютное совпадение с сервером игры. Некоторые продвинутые планировщики талантов и обликов присутствуют в движке, но их UI-планирование требует отдельного подключения.
