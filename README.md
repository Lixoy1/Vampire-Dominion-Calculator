# Наследие вампиров — Crimson Obsidian V6

Бесплатный Telegram Mini App и веб-помощник для Vampire Dominion в оформлении Crimson Obsidian. Нет VIP/Plus, подписочных блокировок и платных лимитов на локальные профили. Точность игровых формул проверяется отдельно от доступности функций.

## Что уже есть в проекте

- Девять разделов: Господство; Конклав и Сад; Уровни и Кровь; Таланты и Опыт; Вдохновения и Веяния; Кровные узы; Облики; Призыв; Сумка и Очки.
- Несколько локальных профилей, ручной ввод состояния, сохранение в браузере и JSON импорт/экспорт.
- Светлая и тёмная темы, русский и английский языки.
- Каталог текущей сборки: 68 Хранителей, 45 Возлюбленных, 237 предметов и 105 обликов.
- 8 ступеней прорыва, 180 уровней Конклава, 210 уровней Сада, 155 строк кривых Веяний.
- 496 оригинальных локальных WebP-иконок в `assets/icons/`; существующие изображения сохраняются.
- Расчёты Конклава, Сада, уровней, Кровных уз, сумки, близости, привлекательности и опыта Гильдии. Кровь и Кровные узы явно помечены как ориентировочные до полного серверного сопоставления.
- Автораспределение Конклава и Сада, а также подбор доступных шагов уровней Хранителей. Это пока не полный Oracle по всем ресурсам.
- Применение плана через общий атомарный резерв сумки: один предмет нельзя потратить дважды на разные шаги.
- Проверка условий призыва Хранителей и Возлюбленных. Неизвестная или нулевая стоимость сама по себе не считается доказательством бесплатного призыва.
- Импорт фактического JSON-ответа калькулятора: отдельная карточка показывает серверный итог, четыре атрибута и доступные разложения по системам.

## Telegram-бот

Сервер использует grammY. Команды `/start`, `/open` и `/help` открывают Mini App; также настраивается кнопка меню Telegram. Сервер проверяет подпись `initData` Telegram и не передаёт BOT_TOKEN в браузер.

Для запуска бота задайте `BOT_TOKEN` и публичный `APP_URL` (или `RENDER_EXTERNAL_URL`). Без BOT_TOKEN веб-приложение продолжает работать, а Telegram-бот не запускается.

## Локальный запуск

Требуется Node.js 20+.

```bash
npm install
npm run check
npm test
npm run verify:icons
npm start
```

Сервер по умолчанию слушает порт 10000. Health-check: `/api/health`.

## Проверка расчётов и ограничения

Сохранённые ответы калькулятора нормализуются адаптером `js/snapshot-adapter.js`. Он хранит исходный JSON, различает `null` и ноль, а также позволяет сравнивать итог и четыре атрибута локального расчёта с серверным снимком. Это не означает live-синхронизацию с игрой.

В эталонном коде стоимость уровней в Крови и Кровных уз обозначена как приближённая. Её нельзя называть точным повторением серверной формулы, пока не будут собраны контрольные точки по уровням и проверены граничные значения. Аналогично, поля `next_gain` относятся к следующему шагу, а не автоматически ко всему плану.

Текущая сборка каталога имеет 237 предметов и 105 обликов. В более позднем полученном JSON каталога указано 240 предметов и 108 обликов. Эти записи ещё требуется сопоставить по ID и добавить без удаления старых элементов; расхождение намеренно не скрывается.

Для полной автоматической синхронизации с игровым аккаунтом нужен официальный API/SDK или поддерживаемый разработчиком экспорт. Telegram `initData` подтверждает пользователя Telegram, но не является авторизацией в Game of Vampires. Проект не просит пароль игры, игровые cookies или session-токены.
