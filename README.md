# Хроники Наследия — Crimson Obsidian

Серверный калькулятор Vampire Dominion без VIP-блокировок: игрок вручную вводит фактические значения из игры, а единый Oracle на Render выполняет расчёты. Девять рабочих разделов: Господство; Конклав и Сад; Уровни и Кровь; Таланты и Опыт; Вдохновения и Веяния; Кровные узы; Облики; Призыв; Сумка и Очки.

## Что включено

- Каталог из 68 смотрителей, 45 партнёров, 237 предметов и 105 обликов.
- 8 ступеней прорыва, 180 уровней Конклава, 210 уровней Сада и 155 строк кривых Веяний.
- 496 оригинальных локальных WebP-иконок; изображения загружаются из `assets/icons/` без CDN.
- Серверный Oracle для расчёта Господства, Конклава, Сада, уровней, талантов, Вдохновений, Веяний, Кровных уз, призыва, сумки, Близости, Влечения и опыта Гильдии.
- Мастер создания аккаунта с выбором региона EU / AS / US, номера сервера и портрета; ручной ввод крови, очков, уровней, талантов, свитков, рукописей и предметов через сенсорную цифровую клавиатуру с множителями K/M/B/T; несколько профилей, локальное сохранение и импорт/экспорт JSON.
- Автораспределение Конклава, Сада, уровней смотрителей, свитков и рукописей талантов; один общий остаток сумки учитывает материалы прорыва, талантов и призыва.
- Атомарное применение плана: сначала проверяются все ресурсы, затем списываются Кровь, очки Конклава/Сада, материалы прорыва и талантов, очки Доверия и фрагменты призыва.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run check
npm test
npm start
```

Также проект можно публиковать как статический сайт: `index.html` — точка входа.

## Происхождение каталога

Текущий встроенный каталог — справочная база проекта. Полученные из API бота «Помощник Дампира» каталоги и ограничения считаются сторонним справочным источником, а не подтверждёнными ответами Game of Vampires. Oracle явно возвращает `catalogProvenance` и `gameVerification`; пока независимая сверка с игрой не проведена, статус подтверждения игры — `not-verified`. Перед заменой встроенной базы требуются полные JSON-ответы, проверка схемы и регрессионное сравнение. Числа из краткой сводки API (240 предметов и 108 обликов) пока не считаются импортированными в `js/data.js`.

## Server Oracle

Все расчёты, влияющие на игровые числа, выполняются на backend Render в `oracle.js`. Браузер отправляет введённые игроком `account` и `plan`, получает версионированный ответ и только отображает его. При недоступности Oracle приложение не подменяет серверный результат локальной формулой.

Игрок самостоятельно переносит значения из своего игрового клиента: Кровь, очки Конклава и Сада, уровни смотрителей, таланты, свитки, рукописи, очки Доверия, Близость и количество предметов. Oracle не входит в Game of Vampires, не получает игровой токен, пароль, cookies или данные аккаунта напрямую.

Основные маршруты:
- `GET /api/oracle/meta` — версия Oracle, схемы, доступные разделы и оговорки точности.
- `POST /api/oracle/calculate` — полный сводный расчёт по переданному профилю и плану.
- `POST /api/oracle/auto-conclave` — серверное распределение Конклава.
- `POST /api/oracle/auto-talents` — распределение свитков и рукописей по ожидаемому приросту Господства.
- `POST /api/oracle/auto-distribute` — общий план: Конклав, Сад, уровни, материалы прорыва, таланты и доступные призывы.
- `POST /api/oracle/commit-plan` — проверка ресурсов и атомарное применение плана к копии профиля.
- `POST /api/oracle/summon` — серверная проверка и призыв смотрителя с корректным списанием предметов.
- `POST /api/oracle/summon-lover` — серверная проверка и призыв возлюбленной с корректным списанием предметов.
- `POST /api/oracle/import-helper` — проверенный импорт нескольких JSON-снимков из API «Помощника Дампира» в ручной профиль (смотрители, Кровные узы, облики, атрибуты Конклава, предметы и опыт Гильдии).


## Импорт JSON из «Помощника Дампира»

В верхней панели Mini App есть кнопка «Импорт дампа». Можно выбрать несколько отдельных JSON-файлов с ответами API помощника. Импортёр сверяет ID с локальным каталогом и переносит поддерживаемые поля в профиль: уровни и прорывы смотрителей, опыт талантов, уровни Кровных уз по ID шаблонов, уровни обликов, четыре атрибута Конклава и опыт/уровень Гильдии. Нераспознанные строки пропускаются и учитываются в отчёте.

`filled` и `dominance` сохраняются только как наблюдения источника; они не подменяют формулы Oracle и не добавляются к итоговому Господству. Происхождение импорта отмечается как сторонний API, не подтверждённый сервером Game of Vampires. После импорта проверьте значения Доверия/Близости и остальные ресурсы, которых нет в выбранных JSON-файлах.

Oracle stateless: профиль не сохраняется на backend. Он возвращается клиенту и остаётся в локальном хранилище игрока или его JSON-резервной копии. Telegram Bot Token остаётся только в серверной переменной окружения и не передаётся в браузер.

Подробнее: `docs/ORACLE_ARCHITECTURE.md`.

## Ограничения расчётов

Таланты: UI-планировщик распределяет свитки и рукописи по эффективности, соблюдает потолок выбранного прорыва и списывает ожидаемое число попыток рукописей по звёздности таланта. Автораспределение собственного опыта талантов пока не подключено. Для обликов показываются уровни и стоимость ткани; автоматический выбор облика не включён, пока не подтверждена формула прироста `next_gain`. Формулы стоимости уровней в Крови и Кровных уз остаются приближёнными. Ни одна из этих оговорок не снимается тем, что расчёт выполняется на сервере проекта.
